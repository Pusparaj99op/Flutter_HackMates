# Icon Assets

Please download or create the following icon files and place them in this directory:

## Required Files (all 512x512px PNG):

### 1. app_icon.png
- **Purpose**: App launcher icon
- **Design**: Green leaf + "EQ" text logo
- **Colors**: Green (#4CAF50) on white background
- **Source**: https://www.flaticon.com or create custom
- **Search**: "leaf", "eco", "environment"

### 2. scan.png
- **Purpose**: "Scan Plastic" AR challenge icon
- **Design**: Magnifying glass or QR scanner
- **Colors**: Green theme
- **Source**: https://www.flaticon.com
- **Search**: "scan", "magnifying glass", "search"

### 3. tree.png
- **Purpose**: "Plant Tree" AR challenge icon
- **Design**: Tree or plant
- **Colors**: Green theme
- **Source**: https://www.flaticon.com
- **Search**: "tree", "plant", "nature"

### 4. bike.png
- **Purpose**: "Bike Route" AR challenge icon
- **Design**: Bicycle
- **Colors**: Green or blue theme
- **Source**: https://www.flaticon.com
- **Search**: "bicycle", "bike", "cycling"

## How to Download:

1. Go to https://www.flaticon.com
2. Search for the icon type
3. Select an icon you like
4. Download as PNG (512x512px)
5. Save to this directory with exact name listed above

## Tools:

- **Flaticon**: https://www.flaticon.com (free with attribution)
- **Icons8**: https://icons8.com (free/paid)
- **Canva**: https://www.canva.com (create custom icons)
