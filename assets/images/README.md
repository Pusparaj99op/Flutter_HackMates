## How to Create:

### Option 1: Download from Undraw.co
1. Go to https://undraw.co
2. Search for the theme
3. Customize colors to match our theme
4. Download as SVG
5. Convert to PNG 1080x1920px using online converter

### Option 2: Use Placeholder
1. Create solid color backgrounds with text
2. Green for slide1, Blue for slide2, Yellow for slide3
3. Add simple icon in center

## Tools:

- **SVG to PNG Converter**: https://cloudconvert.com/svg-to-png
- **Image Resizer**: https://www.iloveimg.com/resize-image
- **Figma** (free): Create custom illustrations

## Fallback:

If images are not available, onboarding will display icons instead.
