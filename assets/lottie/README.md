# Lottie Animations

Please download the following Lottie animation files and place them in this directory:

## Required Files:

### 1. splash.json
- **Purpose**: Splash screen animation (2 seconds)
- **Download from**: https://lottiefiles.com/animations/splash-screen
- **Search terms**: "eco", "leaf", "nature", "loading"
- **Recommended**: Green leaf animation or earth spinning
- **Size**: < 100KB recommended

### 2. confetti.json
- **Purpose**: Challenge completion celebration
- **Download from**: https://lottiefiles.com/animations/confetti
- **Search terms**: "confetti", "celebration", "success"
- **Recommended**: Colorful confetti burst animation
- **Size**: < 100KB recommended

## How to Download:

1. Go to https://lottiefiles.com
2. Search for the animation type
3. Click on the animation you like
4. Click "Download" button
5. Select "Lottie JSON" format
6. Save the file to this directory with the exact name listed above

## Fallback:

If animations are not available, the app will display static icons instead. The app will still function normally.
